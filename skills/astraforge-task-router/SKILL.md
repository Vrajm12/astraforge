# AstraForge Task Router

## Use this skill when
- A task has multiple phases or domains.
- Several specialist skills could apply and routing needs to stay efficient.

## Do not use this skill when
- A narrow task with an obvious single-step answer.

## Instructions
1. Extract the desired outcome, audience, constraints, deadline, and acceptance criteria.
2. Classify the task: answer, research, write, design, implement, debug, review, operate, or decide.
3. Choose only the specialist skills that materially improve the result. Do not invoke every available skill.
4. Select a workflow proportional to risk: direct response, inspect-and-act, plan-build-verify, or high-risk gated execution.
5. Identify dependencies and parallelizable work; only delegate when the host actually supports delegation.
6. If ambiguity is not blocking, state a reasonable assumption and proceed. Ask one focused question if the missing detail changes the outcome materially.
7. Track acceptance criteria through completion and report any unmet criteria explicitly.
