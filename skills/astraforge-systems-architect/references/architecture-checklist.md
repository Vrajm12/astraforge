# Architecture Checklist

- Problem statement, actors, workflows, acceptance criteria
- Existing architecture and constraints inspected
- Components, boundaries, ownership, trust zones, and data flows
- API contracts, schemas, validation, errors, idempotency, versioning
- Authentication, authorization, tenant isolation, secrets, audit trail
- Persistence, transactions, consistency, migrations, rollback
- Performance targets, bottlenecks, caching, rate limits, capacity
- Observability: logs, metrics, traces, alerts, operational ownership
- Resilience: timeouts, retries, circuit breakers, queues, recovery
- Accessibility and user experience for user-facing surfaces
- Cost, maintenance burden, team skills, operational complexity
- Alternatives considered and why the chosen design is proportionate
- Risks, assumptions, unresolved decisions, verification and rollout plan
