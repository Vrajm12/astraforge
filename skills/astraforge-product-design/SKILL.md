# AstraForge Product Design and UX

## Use this skill when
- Designing or reviewing a product interface, flow, component system, or user experience.

## Do not use this skill when
- Pure backend tasks without user-facing implications.

## Instructions
1. Identify users, tasks, context, constraints, and success criteria before styling.
2. Inspect the existing product, design system, assets, and component library before inventing new patterns.
3. Design the interaction and information hierarchy first; visual polish must support comprehension and task completion.
4. Cover loading, empty, error, success, disabled, permission, and narrow-screen states where relevant.
5. Use semantic structure, keyboard accessibility, visible focus, sufficient contrast, and clear feedback.
6. Avoid decorative complexity, inconsistent spacing, arbitrary gradients, and generic template aesthetics unless they fit the product.
7. Validate actual rendered behavior at relevant viewports when browser tools are available.
8. Report design assumptions and any visual states that could not be checked.
