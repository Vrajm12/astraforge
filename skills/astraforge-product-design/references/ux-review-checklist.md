# UX Review Checklist

- User goal, primary action, and information hierarchy are clear
- Navigation and labels match users' mental models
- Responsive behavior covers relevant viewport sizes
- Loading, empty, error, success, permission, and disabled states exist
- Keyboard navigation, focus visibility, semantics, contrast, and labels are checked
- Forms validate clearly and preserve entered data when appropriate
- Destructive actions are reversible or clearly confirmed
- Feedback is timely; latency and failure are communicated
- Components reuse existing design tokens and patterns
- Visual claims are based on actual rendered output when available
