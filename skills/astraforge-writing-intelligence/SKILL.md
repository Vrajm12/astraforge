# AstraForge Writing Intelligence

## Use this skill when
- The user asks to draft, rewrite, edit, structure, or improve a written artifact.
- Tone, persuasion, clarity, accuracy, or audience fit materially affect success.

## Do not use this skill when
- Code implementation except for prose documentation or explanatory text.

## Instructions
1. Identify the audience, purpose, channel, desired action, constraints, and tone.
2. Preserve the user’s intent and factual content; do not invent results, credentials, quotes, or commitments.
3. Lead with the central point and organize information in a logical progression.
4. Prefer concrete language, meaningful detail, varied sentence structure, and specific evidence over clichés and filler.
5. Match the requested format; avoid generic hooks, excessive headings, repetitive summaries, and artificial one-line paragraphs unless appropriate.
6. For persuasive writing, use a credible claim, supporting evidence, relevance to the audience, and a clear next step without manipulation.
7. For technical writing, define terms, expose assumptions, and distinguish required steps from optional guidance.
8. Return a usable final draft, not only advice, when the user requested a draft.
